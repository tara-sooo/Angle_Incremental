## Angle Incremental 0.11.1

### 主な変更

- 最大1,000,000ティックのオフライン進行について、高負荷状態での処理量を抑えて復帰時の応答性を改善しました。
- オフライン中のAuto Infinityによる不要なゲーム全体UI更新を抑制しました。
- Normal Angle / Infinite Angleのcore-hit処理にresume全体のwork budgetを導入し、極端な状態でも計算量が際限なく増えないようにしました。
- 小規模なcore-hit batchは正確な離散処理を維持し、高負荷時に近似処理を使用した場合はオフライン進行レポートへ精度低下を反映します。
- 初回Infinity到達とScore実績解除が同じオフライン処理内で発生する場合の処理順序を修正しました。
- 長時間・高負荷のオフライン進行、Auto Infinity、Normal Angle / Infinite Angleの境界ケースを対象とする回帰・性能テストを強化しました。

### セーブ互換性

`SAVE_VERSION` は10のままで、既存セーブとの互換性を維持しています。
