# Angle Incremental 0.13.2

0.13.2は、ブラウザ側でJavaScriptの確認ダイアログを抑制した場合に、重要操作が実行できなくなる問題を修正するパッチリリースです。

## 修正

- Timelineリスペックの確認を、ブラウザ標準の `window.confirm()` からゲーム内の確認ダイアログへ変更しました。
- セーブデータのリセット、チェックポイント復元、pre-import復元、undo復元、quarantine復元も同じゲーム内確認ダイアログを使用するよう変更しました。
- ブラウザ側でJavaScriptダイアログが非表示・抑制されていても、これらの操作が使用不能にならないようにしました。
- 確認・キャンセル、Escキー、フォーカス復元、日本語/英語、モバイル表示を回帰テストで検証します。

## 互換性

- `SAVE_VERSION` は11のままです。
- Timelineのリスペック仕様、セーブデータ形式、復旧処理の意味、ゲームバランスに変更はありません。
