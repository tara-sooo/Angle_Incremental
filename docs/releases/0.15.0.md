# Angle Incremental 0.15.0

0.15.0では、Timeline TreeをAD30まで拡張し、長期進行、操作性、セーブ復旧の信頼性を改善します。

## Timeline Tree：AD30まで拡張

従来のBC16500の2ノードにBC6000とAD30を追加し、合計6ノードになりました。各時代でReal / Parallelの一方を選択し、次の時代のルートは独立して選べます。ノードはリスペックして選び直せます。

| ノード | コスト | 効果 |
| --- | ---: | --- |
| Real-BC16500 惰性の打製石器 | 1 TF | 現在のIPに応じてInfinity回数の獲得量を強化します（獲得量 × (1 + log10(IP))）。 |
| Parallel-BC16500 終わらない氷河期 | 1 TF | IC8クリア後、IP獲得量が毎秒×3ずつ増加します。×1e10を超える部分にはソフトキャップが適用されます。 |
| Real-BC6000 チグリスとユーフラテスの狭間に | 1 TF | IC6のInfinity回数報酬に、Eternityごとに追加×1.2を適用します。追加倍率は×1e10以降ソフトキャップします。 |
| Parallel-BC6000 三角州の中の暮らし | 1 TF | Towerのスコア累乗の増加量を+^0.05/Floorから+^0.07/Floorに変更します。 |
| Real-AD30 復活する神の子 | 5 TF | 現在のScoreに応じてEternity獲得量を乗算します（獲得量 × (1 + log10(Score) / 10000)）。 |
| Parallel-AD30 死後にはできない人間宣言 | 5 TF | 現在のInfinity回数に応じてEternity獲得量を乗算します（獲得量 × (1 + log10(Infinity回数) / 2)）。追加ソフトキャップはありません。 |

## 操作

- M / MAX、G / GEN、B / CB、I / INF、E / ETRのゲームプレイ用ホットキーに対応しました。長押しでの連続操作もできます。
- モバイル用クイック操作バーを追加しました。ホットキーとバーの表示は設定で切り替えられます。

## セーブと復旧

- メインセーブとバックアップを統一し、起動時の復旧、インポート、復元、リセットをより安全にしました。
- 複数タブやオフライン進行時の保存を保護します。ブラウザ保存領域の状態・使用量を確認できます。
- セーブを外部ファイルへ書き出して読み込めるようになりました。ブラウザの保存データを失った場合も、手元のバックアップから復元できます。
- 32×32、64×64のfaviconと180×180のタッチアイコンを追加し、ブラウザでのアイコン表示を改善しました。

既存のセーブデータはそのまま引き継げます。進行状況のリセットは必要ありません。
