## Angle Incremental 0.13.0

### 主な変更

- Tower Challenge 4をANGLE側の専用A/B/C強化で攻略する最終形を維持しました。TC4クリアとIP条件を満たしたとき、Eternityをプレイヤー操作で実行できます。
- Eternity Milestone 1-1〜1-3は、Eternityごとに未取得の1つを選べる取得権方式になりました。Milestone 2〜10はEternity 5 / 8 / 12 / 20 / 27 / 44 / 81 / 108 / 128で順に有効になります。IC7、GR/CBの下位リセット抑止、CB要求軽減、IU/IA/Tower自動化、IP初期値、Break Eternityなどの効果をMilestone画面で確認できます。
- 最初のTimeline時代（BC16500）を追加しました。Score / IP / Eternityの独立した3トラックからTime Fragment（TF）を獲得し、RealまたはParallelのルートを選んでノードを購入できます。両ルートは同じ時代では排他的です。
- TFの獲得、ノード購入、ルート状態、Timelineのリスペックと再周回境界を保存できるようにしました。リスペックでは購入済みノードのTFが戻り、獲得済みTFとTimelineの発見状態は保持されます。
- Eternity / Timelineを独立した操作面から確認できるナビゲーション、レスポンシブ表示、Timeline TF概要を整理しました。Helpの進行状況別説明、Offline Progressの結果表示、非表示タブ設定、Infinityの大きなIP表示と自動化も改善しました。
- Infinity後半からEternityまでの表示・実行境界、TC4、Eternity、Milestone、Timelineの回帰・性能カバレッジを強化しました。

### セーブ互換性

`SAVE_VERSION` は11です。0.12.2で使用していた保存形式10のセーブは自動的に11へ移行され、既存の進行・設定・実績を保ったまま読み込めます。Milestone 1-3の旧IA実効レベルも、購入レベルと無料効果へ安全に分離されます。

### 今回含まれないもの

- 後続Timeline時代、Topology、Eternity Point（EP）経済、Auto Eternity
- 0.14.0で予定するANGLE / IA / Prestigeの大規模な再設計・表示変更
