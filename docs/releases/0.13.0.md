## Angle Incremental 0.13.0

### Eternity

- Eternity Milestone 6〜10を追加しました。
  - Milestone 6（Eternity 27）: 新しいEternity周回をIC1〜IC8クリア済みで開始
  - Milestone 7（Eternity 44）: Tower Challengeが通常の解放条件を満たした時点で自動クリア
  - Milestone 8（Eternity 81）: Infinite Angle強化の自動購入とTower自動建設を解放
  - Milestone 9（Eternity 108）: 新しいEternity周回を1000 IP所持した状態で開始
  - Milestone 10（Eternity 128）: Break Eternityを発生させ、Infinity Pointの1.80e308上限を撤廃
- 既存のEternity Milestoneの挙動を仕様に合わせて修正しました。
  - Milestone 1-2の無料通常強化レベルを通常のレベルと区別して表示
  - Milestone 1-3を、購入価格を増加させないIA強化の無料+5レベルとして処理
  - Milestone 2で新しいEternity周回をIC7クリア済みの状態から開始
  - Milestone 5でAuto InfinityではなくInfinity Upgrade自動購入を解放
- Eternity周回の現在時間・最速記録・直近10周を確認できるEternity統計を追加しました。

### Timeline

- 初回Eternityで解放される新要素「Timeline」を追加しました。
- Score / Infinity Point / Eternity回数の3つの独立した条件からTime Fragment（TF）を獲得し、Timelineのノード購入に使用できます。
- 最初のTimeline時代「BC16500」を追加しました。
  - `Real-BC16500 惰性の打製石器`：現在のIPに応じてInfinity Point獲得量を強化
  - `Parallel-BC16500 終わらない氷河期`：IC8クリア後の経過時間に応じてInfinity Point獲得量を強化
- 同じ時代ではReal / Parallelのどちらか一方のルートのみ取得できます。
- Timelineをリスペックすると購入したノードのTFがすべて返却され、現在のEternity周回を最初からやり直します。獲得済みTFとTFの取得履歴は保持されます。
- TFの取得履歴とTimelineの購入状態はセーブされ、通常のEternityでは購入済みノードを保持します。

### UI・表示

- 下部ナビゲーションをコンパクトな1行タブバーへ変更しました。進行に応じて必要なタブが表示され、SETから表示するタブを選択できます。
- Eternity画面に `Milestone / Timeline` のサブタブを追加し、TimelineをEternityから操作できるようにしました。
- TC4専用A/B/C強化をChallenge画面からANGLEへ移動しました。
- Helpを大幅に拡張し、ANGLEからEternity / Timelineまでの解放済み要素をゲーム内で確認できるようにしました。
- Offline Progressの結果画面を、処理内部の情報ではなく、オフライン中に実際に変化したリソースを表示する形式へ変更しました。
- Save / Import / Recovery、Settings、Statistics、Challengeなどの画面構成と操作性を整理しました。
- デスクトップ・タブレット・モバイルで、タブ、サブタブ、スクロール、ANGLE / Infinite Angle、Timelineなどのレスポンシブ表示を改善しました。

### 数値・不具合修正

- e308を超えるInfinity Point獲得量が1.80e308で止まって表示される問題を修正しました。Infinity履歴やAuto Infinityの判定でも正しい獲得量を扱うようになりました。
- 所持リソースの科学表記が購入条件を実際より早く超えて見えないよう、境界付近の数値表示を修正しました。
- その他、Eternity / Timeline進行、ナビゲーション、表示に関する不具合を修正しました。

### セーブ互換性

`SAVE_VERSION` を10から11へ更新しました。

0.12.2の保存形式10のセーブは自動的に形式11へ移行され、既存の進行・設定・実績を保持したまま読み込めます。

Milestone 1-3を取得済みの既存セーブでは、従来のIAレベルを購入レベルと無料+5レベルへ移行します。
