# Angle Incremental 0.13.1

0.13.1 is a compatibility-focused patch release built from the accepted 0.13.0 release line and the frozen next candidate.

## Changes

- Offline Progress now completes the supported 1,000,000-tick workload much faster while preserving requested and processed tick accounting.
- The ANGLE playfield and Generation-Core Boost reset dock no longer overlap on short desktop viewports.
- Desktop main tabs can be placed on the Right or Bottom, while mobile and constrained layouts use Bottom automatically. The desktop preference is restored when the layout becomes eligible again.
- Achievements 42-44 cover Eternity Milestone 1-2 and the BC16500 Real and Parallel Timeline routes.
- Real-BC16500 now strengthens Infinity count gain using held IP: original gain × (1 + log10(IP)). Parallel-BC16500 remains the Infinity Point gain route.
- GitHub Actions dependency installation now uses bounded, cached installs for more predictable development and validation runs.

## Save compatibility

SAVE_VERSION remains 11. Existing 0.13.0 and earlier supported saves remain loadable, and no new save-schema migration is required.
