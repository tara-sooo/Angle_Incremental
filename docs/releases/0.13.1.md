# Angle Incremental 0.13.1

0.13.1は、リリース済みの0.13.0系統と凍結済みのnext候補を統合した、互換性重視のパッチリリースです。

## 変更点

- Offline Progressの100万ティック処理を大幅に高速化し、要求ティック数と処理済みティック数の整合性を維持しました。
- 縦幅の短いデスクトップ画面で、ANGLEのプレイフィールドとGeneration / Core Boostのリセット操作が重ならないよう修正しました。
- デスクトップではメインタブの位置を「右」または「下」から選べるようになりました。モバイルや制約のあるレイアウトでは自動的に下部配置になり、デスクトップ向けの設定は再び適用可能な画面に戻ると復元されます。
- Eternity Milestone 1-2と、BC16500のReal / Parallelルートに対応する実績42〜44を追加しました。
- Real-BC16500は、現在所持しているIPに応じてInfinity数獲得量を「元の獲得量 × (1 + log10(IP))」で強化するよう修正しました。Parallel-BC16500は引き続きIP獲得量を強化します。
- GitHub Actionsの依存関係インストールにキャッシュと時間制限を導入し、開発・検証時の実行を安定化しました。

## セーブ互換性

SAVE_VERSIONは11のままです。0.13.0以前の対応セーブは引き続き読み込み可能で、新しいセーブ形式への移行は不要です。
