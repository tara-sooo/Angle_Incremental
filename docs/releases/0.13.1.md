# Angle Incremental 0.13.1

0.13.1は、Offline Progressやデスクトップ表示の改善、実績追加、Timelineの修正を含むパッチリリースです。

## 変更点

- Offline Progressの100万ティック処理を大幅に高速化し、要求ティック数と処理済みティック数の整合性を維持しました。
- 縦幅の短いデスクトップ画面で、ANGLEのプレイフィールドとGeneration / Core Boostのリセット操作が重ならないよう修正しました。
- デスクトップではメインタブの位置を「右」または「下」から選べるようになりました。モバイル・縦画面など、右配置を利用できないレイアウトでは下部に固定され、デスクトップ向けの設定は再び適用可能な画面に戻ると復元されます。
- 実績42〜44を追加しました。Eternity Milestone 1-2の取得や、BC16500のReal / Parallelルートの購入で解除されます。
- Real-BC16500は、現在所持しているIPに応じてInfinity数獲得量を強化するよう修正しました。Parallel-BC16500は引き続きIP獲得量を強化します。
- GitHub Actionsの依存関係インストールにキャッシュと時間制限を導入し、開発・検証時の実行を安定化しました。
