## Angle Incremental 0.12.1

### 修正

- EternityをInfinity内のサブタブから分離し、独立したトップレベルのメインタブへ移動しました。
- Infinityのサブタブ構成を `Upgrades / Infinite Angle / Tower` の3つへ戻しました。
- 0.12.0で発生していたEternity UIのレイアウト崩れを修正しました。
- ブラウザ/E2E回帰テストで、Eternityが独立タブであることとInfinity側にEternityサブタブが存在しないことを検証します。

### 互換性

`SAVE_VERSION` は10のままです。TC4、Eternity条件、Milestone、実績、Time Flux保持を含むゲーム進行・バランス・セーブ仕様に変更はありません。

このリリースはUI/navigationのみのパッチです。Eternity Point / EP、Break Eternity、追加Milestoneなどの新しいゲーム要素は導入しません。
