# Angle Incremental 0.14.0

0.14.0では、オフライン進行の高速化、自動化まわりの改善、進行・セーブの安定化、操作性の改善を行いました。

## オフライン進行

- Offline Progressの処理を大幅に改善しました。Auto Infinity、Generation、Core Boost、自動購入、各種解放などを考慮しながら、安全な区間をまとめて処理するようになりました。
- Timelineを使用している状態でも、安全な場合は高速なオフライン進行を利用できるようになりました。
- 安全にまとめて処理できない状態では、従来の処理へ自動的に切り替わります。

## Eternity・自動化

- Eternity Milestone 5で、通常の条件を満たすとInfinite Angleが自動で解放されるようになりました。
- Eternity Milestone 6で、通常の条件を満たすとBreak Infinite Capが自動で行われるようになりました。
- Eternity Milestone 7のTower Challenge自動クリア対象をTC1～TC4に限定しました。
- Auto Generationの最低時間設定が、Eternity Milestone 3有効時でもGenerationごとに正しくリセットされるようになりました。
- Eternity Milestone 2 / 6が有効なセーブを読み込んだ際、Infinity Challengeのクリア状態が正しく反映されるようになりました。

## 進行・数値の修正

- TC4中は通常強化・IA強化を購入できないようになり、TC4専用のA / B / C強化だけを使用する本来の仕様になりました。
- 初回Infinity直前で、大量の小さなScore獲得をまとめた際にInfinity条件を超えられないことがある問題を修正しました。
- バッチ処理中のScore計算を修正し、Achievementの取得タイミングなどが通常進行とずれることがある問題を改善しました。
- Eternity回数などの大きな整数値を、JavaScriptの安全な整数範囲を超えた後も正しく扱えるようにしました。

## 操作・表示

- Infinity Upgradeをダブルクリックで直接購入できるようになりました。
- Infinity UpgradeとTimelineノードで、モバイルのダブルタップ購入に対応しました。
- Timelineノードもダブルクリック / ダブルタップで直接購入できるようになりました。
- Timelineのノード説明、接続線、購入済みルートの表示を改善しました。
- lap speedのソフトキャップ表示をコンパクトな`SC`表記に変更しました。
- Helpを、内部仕様中心の説明からプレイヤー向けの案内へ整理しました。
- Angle Incrementalのアイコンをfaviconとして追加しました。

## セーブ

- 壊れたセーブが隔離されたあとにページを再読み込みしても、復旧状態が維持されるようになりました。
- 既存のセーブデータは進行を引き継いで0.14.0の保存形式へ移行します。
