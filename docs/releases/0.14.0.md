# Angle Incremental 0.14.0

0.14.0はOffline Progress v2を中心としたリリースです。長時間の離席後も重要な進行イベントを保ちつつ、設定したtick数に依存しにくい形で効率よく再開できます。

## 進行とセーブの信頼性

- オフライン中の自動化、購入、解放、Timelineなどの離散イベントを考慮した進行処理を追加し、安全な一括処理ができない場面では従来の処理へ切り替えます。
- セーブ復旧、数値の精度、Eternity後の進行や自動化を改善しました。
- 既存のセーブデータは進行を引き継いで新しい保存形式へ移行します。

## 操作と案内

- Infinity UpgradeとTimelineノードの直接購入操作を改善しました。
- Helpを進行に沿ったプレイヤー向けの案内に整理しました。
- Angle Incrementalのfaviconを追加しました。

Timelineに新しい時代やノードは追加していません。BC16500の既存ルートと効果はそのままです。
